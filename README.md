## Featured Projects

### Audix — *actively building*
An AI-powered video intelligence platform, designed so users can upload a video and get contextual information about what's happening in it. The project combines media processing with FFmpeg and AI/ML services to extract structured context — recognizing music, identifying scenes, and surfacing related media information — from unstructured video input.

**Tech:** React · TypeScript · Node.js · Express · FFmpeg · AI/ML services

**Planned capabilities** *(not yet implemented)*:
- Video upload and processing pipeline
- Music recognition within video content
- Movie/series scene recognition
- Actor and media context lookup
- AI-driven scene and context analysis
- Media metadata extraction



---

### DevTrack — *early development*
A developer workflow and issue management platform inspired by modern developer tools. The core challenge is designing a data model and workflow engine that can represent issues, projects, and collaboration cleanly enough to scale as features are added.

**Tech:** React · TypeScript · Node.js · PostgreSQL

**Core direction:**
- Issue tracking and management
- Project and workflow organization
- Developer collaboration features



---

### SecureShare — *built*
A security-focused platform for controlled, temporary sharing of sensitive information. The project focuses on secure architecture, time-limited access, and cloud-backed infrastructure rather than gating access behind a simple UI toggle.

**Tech:** React · TypeScript · Node.js · Supabase · Azure

**Features:**
- Secure, time-limited information sharing
- Security-focused backend architecture
- Cloud-backed infrastructure with Azure integration



---

### HostelHub — *built*
A mobile-first hostel management platform designed to simplify everyday hostel services and requests, covering authentication, service requests, commerce, and payments in a single app.

**Tech:** Flutter · Dart · Supabase

**Features:**
- Authentication and user management
- Maintenance and service request handling
- Mess and canteen management
- Stock and cart system
- Payment integration
- Document uploads
